# Backend Engineer (Java, NodeJS, TypeScript) - Fintech

**Company:** Finhay · **Location:** 8th Floor, Capital Building, 58 Kim Ma, Ba Dinh, Ha Noi · **Work Mode:** At office

## Core Responsibilities

- Design, develop, and maintain backend services/APIs for fintech products, financial data, and Finhay's internal platforms
- Build stable, secure, scalable RESTful/GraphQL APIs with easy integration capabilities
- Develop business logic for financial data, user accounts, transactions, reports, partner integration, and internal workflows
- Optimize system performance, database queries, caching, queue/job processing, and backend service load capacity
- Participate in system architecture design, data modeling, business flow design, and technical solutions for new features
- Coordinate with Product Owner, QA, DevOps, Data teams to analyze requirements, implement, debug, and operate products
- Ensure code quality through unit tests, integration tests, code reviews, logging, monitoring, and technical documentation
- Maintain smaller Node.js projects including bug fixes, dependency upgrades, source code understanding, and operational support

## System Integration & Data Products

- Integrate with internal and third-party systems like partner APIs, financial data systems, payment, notification, authentication/authorization
- Work with financial data including market data, stock quotes, financial statements, fund NAV, indices
- Design validation, transformation, synchronization mechanisms ensuring data accuracy, consistency, and timeliness
- Support root cause analysis for API responses, data pipelines, latency, timeouts, data inconsistency, production incidents
- Propose improvements to architecture, data quality, developer experience, and system efficiency

## Required Technical Skills

- Minimum 2 years backend development experience with Java
- Proficient in Java Core with hands-on Spring Boot/Spring Framework experience
- Experience designing and developing RESTful APIs with understanding of HTTP methods, status codes, authentication, authorization, rate limiting, pagination
- Experience with relational databases (PostgreSQL/MySQL/MariaDB); SQL knowledge, indexing, transactions, query optimization
- Knowledge of caching, message queues, or background jobs (Redis, Kafka, RabbitMQ, SQS equivalent)
- Experience writing unit/integration tests using JUnit, Mockito, Testcontainers or equivalent
- Familiarity with Git, CI/CD, Docker, and Agile/Scrum development processes
- Ability to read, maintain, and modify Node.js/JavaScript/TypeScript projects when needed; **no Node.js expertise required**, but willingness to learn and solve problems outside Java stack

## Strong Plus Technical Skills

- Experience building fintech, securities, banking, payment, trading, market data systems or products with high data accuracy requirements
- Understanding of microservices, event-driven architecture, distributed systems, observability, logging/metrics/tracing
- Experience with cloud/on-prem deployment, Kubernetes, Helm, Terraform, or system operations tools
- Experience optimizing performance, handling high-throughput APIs, batch processing, or data synchronization
- Knowledge of security best practices: OWASP, secure coding, secrets management, token-based authentication, OAuth2/JWT

## Domain Knowledge (Strong Plus)

- Understanding of financial markets, securities, investment funds, financial data, or metrics like P/E, EPS, ROE, NAV, market cap
- Familiarity with financial data types: stock quotes, financial statements, fund NAV, indices, commodities, transaction data
- Experience at fintech, securities, banking, financial data companies, or B2B API products

## AI Mindset & Application

- Proactively use AI tools like ChatGPT, Claude, GitHub Copilot, or coding assistants to increase daily work efficiency
- Apply AI to software development: requirement analysis, API design suggestions, test case generation, code writing/refactoring, log analysis, debugging, technical documentation
- Ability to evaluate AI-generated results through testing, code review, and technical understanding
- Open-minded toward new technologies; not limited to single tech stack

## Analytical & Soft Skills

- Strong analytical thinking with ability to understand business logic, break down problems, provide appropriate technical solutions
- Careful and responsible toward system quality, especially with financial data and sensitive business flows
- Proactive communication and good collaboration with PO, QA, DevOps, Data, and other stakeholders
- Ownership mentality; willing to debug production issues and follow through until completely resolved
- Ability to read English technical documentation
- Flexibility with technology; prioritize solving problems and creating product value
